# 🛒 Angular E-Commerce App

🔗 Live Demo:
https://ecommerce-project-omega-peach.vercel.app

---

## 🚀 Features

- User Authentication (Login / Register)
- Protected Routes using Auth Guard
- Products & Categories
- Add to Cart
- Checkout & Online Payment
- Orders History
- Responsive Design

---

## 🛠️ Tech Stack

- Angular (Standalone Components)
- Tailwind CSS
- RxJS
- REST API Integration
- Stripe Payment Integration
- Vercel Deployment

---

## ▶️ Run Locally

```bash
npm install
ng serve
```
